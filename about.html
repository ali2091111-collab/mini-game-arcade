About Mini Game Arcade

Mini Game Arcade is a small, static website that offers original browser mini-games you can play for free, without downloading anything or creating an account.

It currently has one game: Slice Rush, a fruit-slicing game built with plain HTML, CSS and JavaScript. All of its fruit, bombs, particles and sound effects are simple shapes and sounds drawn or generated in code — no copied artwork, branding or sound files from other games.

The site is deliberately kept simple: no backend, no database, no accounts and no advertising. New games are added only when they are fully playable and tested, so the homepage never lists a game that does not work.

Site operator: to be added by the site owner. No company name, address or personal details are claimed on this page until the owner supplies them — see the Contact page for what is still needed.
